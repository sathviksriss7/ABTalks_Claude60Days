What is the Personal AI Playbook?

This is your reusable system for working with Claude — not a list of one-off prompts. It stores modular workflow templates for your recurring tasks, plus two builders that assemble prompts from parts so you always know what each piece is doing and why.

Workflows — ready-made, editable templates organized by category, with variables you fill in.
Prompt Builder — assemble a custom prompt from labeled building blocks with a live preview.
Loop Builder — turn any prompt into a self-checking, iterating prompt with clear stop conditions.
My Workflows — everything you save, duplicate, or favorite, searchable and stored on this device.

What is this?

The Personal AI Playbook is a self-contained tool (one HTML file, works offline) for turning how you already use Claude into reusable systems, instead of re-typing prompts from memory every time.

The five sections
  • Dashboard — overview of your categories and favorites.
  • Workflows — ready-made templates for your recurring tasks (status reports, resume tailoring, meeting notes, etc.), each with fill-in variables and a one-click copy.
  • Prompt Builder — build a custom one-off prompt from labeled parts (role, objective, constraints, etc.) with a live preview.
  • Loop Builder — wrap a prompt in a self-review loop with a goal, grading criteria, and a clear stop condition.
  • My Workflows — anything you create, duplicate, or favorite. Saved only in this browser via localStorage.
The track switch

The All / BizOps / AI PM switch in the header filters everything to the career track you're focused on right now, so you're not scanning irrelevant workflows while context-switching between the two.
